# App Info at Startup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Each shell hands the app's own version, build number, platform and bundle id to the core at
startup, so the app reads them synchronously via `cx.app_info()`, already in `init`.

**Architecture:**
- A new last `Action::AppInfo { version, build, platform, bundle_id }` variant in mobiler-ui.
- mobiler-core stores it in a process-wide `RwLock<AppInfo>` (new module `app_info.rs`).
- `MobilerShell::update` builds every `Cx` with a copy of the stored value.
- Each shell (iOS, Android, web) sends the action once, before `Restore` and `Start`.

**Tech Stack:** Rust (Crux core, facet typegen), SwiftUI shell, Kotlin/Compose shell, Leptos/WASM web shell.

**Spec:** `docs/superpowers/specs/2026-09-27-app-info-design.md`

## Global Constraints

- **Additive only.** The `AppInfo` variant goes **last** in `Action`, so existing variant indices
  are unchanged. An app that never calls `cx.app_info()` behaves exactly as on 0.38.
- **Field names:**
  - Rust uses `version`, `build`, `platform`, `bundle_id`, all `String`.
  - Generated Swift uses `bundleId`; Kotlin uses positional args.
- **Platform strings:** `"ios"`, `"android"`, `"web"`. The empty string means the shell never sent
  the action.
- **iOS:** `version` = `CFBundleShortVersionString`, `build` = `CFBundleVersion`,
  `bundle_id` = `Bundle.main.bundleIdentifier`, each `?? ""`.
- **Android:** `version` = `versionName ?: ""`, `build` = `longVersionCode.toString()`,
  `bundle_id` = `packageName`. minSdk is 34, so no compatibility shim.
- **Web:** `version`, `build` and `bundle_id` are `""`; `platform` is `"web"`.
- **No async `device.app_info` op.** The existing `device` `model` / `locale` ops are untouched.
- **Target versions:** mobiler-ui 0.28.0, mobiler-core 0.39.0, mobiler-web 0.39.0, CLI 0.57.0.
- **Subagent briefs:** never poll with `pgrep -f` or a file-marker `until` loop; run builds in the
  foreground with a timeout.
- **Target dir:** use a per-demo `CARGO_TARGET_DIR=<demo>/target` for demo builds. The global
  target dir links the wrong `shared` crate.

## Review Focus

1. **Order: AppInfo after Start.** If a shell sends `AppInfo` after `Start`, `init` sees empty
   values. The app expects them filled in `init`.
   - Pinned by Task 1 test `init_sees_app_info_sent_before_start`.
   - Every shell task puts the send first.
2. **Shell never sends AppInfo** (old shell, unit tests). The app expects empty strings, not a panic.
   - Pinned by Task 1 test `cx_default_has_empty_app_info`.
3. **AppInfo sent twice** (hot reload, re-created activity). The app expects the latest value to win.
   - Pinned by Task 1 test `later_app_info_replaces_earlier`.
4. **Missing platform values** (no `CFBundleVersion` key, null `versionName`). The app expects `""`
   for that field, never a crash.
   - Pinned by the `?? ""` / `?: ""` in the Task 3 and Task 4 code; reviewers check every field.
5. **AppInfo invokes the app.** `Action::AppInfo` must not reach `update`, `input`, `restore` or
   `init`, and must add no effects beyond `Render`.
   - Pinned by Task 1 test `app_info_action_does_not_touch_the_model`.

- [ ] **Step 4: Create `mobiler-core/src/app_info.rs`**

```rust
//! The app's own version/build, handed to the core by the shell at startup
//! ([`Action::AppInfo`](mobiler_ui::Action::AppInfo)) and read via [`Cx::app_info`](crate::Cx::app_info).

use std::sync::RwLock;

/// The running app's version as the platform knows it — what the store compares on upload.
/// All fields are empty when the shell predates this (it never sent `Action::AppInfo`).
#[derive(Clone, Debug, Default, PartialEq, Eq)]
pub struct AppInfo {
    /// iOS `CFBundleShortVersionString` / Android `versionName` (e.g. `"1.0"`).
    pub version: String,
    /// iOS `CFBundleVersion` / Android `longVersionCode`, as text (iOS allows `"1.2.3"`).
    pub build: String,
    /// `"ios"`, `"android"` or `"web"`.
    pub platform: String,
    /// iOS bundle identifier / Android package name.
    pub bundle_id: String,
}

impl AppInfo {
    const EMPTY: AppInfo =
        AppInfo { version: String::new(), build: String::new(), platform: String::new(), bundle_id: String::new() };
}

// One core per process on every shell, and `MobilerShell` is stateless, so the value lives here.
static APP_INFO: RwLock<AppInfo> = RwLock::new(AppInfo::EMPTY);

/// Replace the stored info (the last `Action::AppInfo` wins, so a hot reload is harmless).
pub(crate) fn set(info: AppInfo) {
    *APP_INFO.write().unwrap_or_else(|e| e.into_inner()) = info;
}

/// A copy of the stored info.
pub(crate) fn get() -> AppInfo {
    APP_INFO.read().unwrap_or_else(|e| e.into_inner()).clone()
}
```

```rust
    /// The app's own version/build/platform/bundle id, as the shell reported it at startup

    /// shows into the Model in `init`.

```
