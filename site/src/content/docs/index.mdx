The three screens above are one Rust crate. The coffee demo has no Kotlin, Swift or JavaScript of its own: the same
`view` function returns the same widget tree, and each platform's shell renders it natively.

:::caution[Experimental]
Mobiler is young and its APIs still change between releases. Every change is listed in the
[upgrade notes](/guides/upgrading/), and `mobiler upgrade` carries an app forward.
:::

<CardGrid>
	<Card title="Write it once" icon="seti:rust">
		State, business rules, validation, navigation, translations, number and date formatting, network calls and the
		screens themselves live in one Rust core. Tests run on your machine with `cargo test`, no emulator needed.
	</Card>
	<Card title="Native on every platform" icon="laptop">
		The core describes the screen as data. A generic shell turns it into Jetpack Compose on Android, SwiftUI on iOS and
		the DOM on the web, so each app looks and behaves like its platform.
	</Card>
	<Card title="Device features from Rust" icon="puzzle">
		HTTP, storage, camera, photos, the clipboard, haptics and more are built in. Thirty-two plugins, some still
		experimental, add SQLite, biometrics, payments, Bluetooth and more, one command each.
	</Card>
	<Card title="Share code with your server" icon="random">
		Put your types and rules in a plain Rust crate, then use it from the mobile core, the web client and an Axum
		server. They agree by construction, because they compile the same code.
	</Card>
</CardGrid>
