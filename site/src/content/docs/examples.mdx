Every demo lives in the [repository's `demos/` folder](https://github.com/mobiler/mobiler/tree/main/demos).
Apart from barbershop, which is the reference the shells are developed in, their Android and iOS shells
are exactly what `mobiler new` and `mobiler plugin add` produce. All the app code is Rust.

## Saldo

A complete money manager: income, expenses and transfers across accounts, categories, charts, recurring
entries, CSV export, backup and restore, five languages and a biometric lock. Built step by step in the
[tutorial](/tutorial/). See [Try Saldo](/try-saldo/).

[Code](https://github.com/mobiler/mobiler/tree/main/demos/saldo) · Android, iOS · plugins: `sqlite`,
`files`, `filepicker`, `biometric`, `picker`

## Barbershop (Fade House)

A booking app that shows off most of the widget set: an icon tab bar and action button, a brand gradient,
an avatar rail with ratings, a date, time and confirm booking sheet, charts, an inline calendar with busy
dots, swipe actions, large controls, a localized calendar and rich form fields. One `app-core` crate runs
the mobile app and the web client.

## Coffee

A storefront: a hero image with an overlay, category chips over a product grid, a detail screen with a
slider and a quantity stepper, and buttons that try the scanner, biometric, secure-store, WebSocket and
notification plugins. One core, three platforms.

## Full-stack todo

The shape of a real product: a `domain` crate shared by an Axum server and every client, one core
running natively on Android and iOS and in the browser, and a second web app with its own Leptos UI that
shares only `domain`. See [One core for mobile, web and server](/guides/full-stack/).

## Full-stack notes (SQLx)

`domain`, and one core for the web and mobile clients.

[Code](https://github.com/mobiler/mobiler/tree/main/demos/fullstack-sqlx) · web, server (mobile by
re-exporting the core from a `mobiler new` app)
